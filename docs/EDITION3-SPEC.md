## Arquitectura y propiedad
10 módulos, 3 lecciones cada uno, orden m1..m10. Todos IDs actividad nuevos `f3-lN-J`, ejercicio `f3-lN-J-choice/order/portfolio`, misión `f3-msNN`. Mantener formatos choice/order/portfolio y motor portfolio honesto; exámenes 3 extra choice por módulo y size6. Progresión lección: problema transferible → ejemplo trabajado → configuración/pasos precisos → fallo/diagnóstico → ejercicio menos guiado → validación → transferencia. Mínimo dos tarjetas sustanciales, tres ejercicios; no rellenar con obviedades de prompting ni distractores absurdos. 10-20 minutos lectura/práctica, indicar tiempo real si tarea exterior mayor. Un programa de aprendizaje de herramientas, no un proceso bancario.

Contenido owns course.json y modules m1,m2,m3,m7,m8,m9,m10 (7 módulos). Evaluación/Studio owns modules m4,m5,m6 y missions.json/lab.json + js/views/lab.js + recursos de agentes (ver debajo); tests/content.test.mjs. Principal owns engine course/state/progress si requiere, home/profile/academy, recursos Office, scripts/tests restantes/cache/docs. Revisor independiente owns docs/CAPACIDADES.md/REVIEW3.md + tests/review3.test.mjs; avisa defectos, no cambia archivos ajenos.

## Módulos, competencias y conceptos (interfaz fija)
m1 criterio "Elegir y dirigir Copilot" — `tools.{route,context,verify}`. Mapa M365Chat vs apps vs Builder vs Studio vs AnalystResearcher vs PagesNotebooks; agentes desde primer ejemplo con criterio cuándo no usarlos; trabajar sin depender especialidad.
m2 contrato "Construir agentes con Agent Builder" — `builder.{contract,configure,iterate}`. Contrato propósito/inputs/outputs/límites; UI configuración instrucciones descripción sugerencias; mejora por fallo observado. Entregar agente que cada alumno adapta a cualquier tarea financiera, ejemplo analizar evidencia documental.
m3 conocimiento "Fuentes, capacidades y pruebas del agente" — `knowledge.{sources,capabilities,test}`. Separación estable/expediente/ejemplos; configuración fuentes; capacidades visibles; contexto vs permisos; pruebas reservadas, contradicción, abstención, regresión.
m4 studio "Copilot Studio: construir la conversación" — `studio.{create,topics,variables}`. Crear desde blanco en sandbox, instrucciones y gen orchestration vs temas; tema flujo determinista para pedir inputs con preguntas/condiciones; variables alcance/tipo/entidades/outputs con ejemplo financiero neutro (período/unidad/métrica) y prueba de ramas. PASOS REALES no solo diagrama.
m5 flujos "Copilot Studio: herramientas y agent flows" — `flows.{contract,build,recover}`. Crear herramienta con contrato; flujo "When an agent calls the flow"/"Respond to the agent", inputs/outputs, try test; receta primero sin conector (comparar dos cifras y devolver delta), luego opcional registro SharePoint/Dataverse con idempotencia/403/timeouts. No tratar prompt llamado tool como acción real. Explicar qué ejecuta y dónde se ve resultado.
m6 ciclo "Copilot Studio: probar, distribuir y gobernar" — `lifecycle.{evaluate,publish,observe}`. Sesiones test y activity trace; banco de pruebas guardado y evaluación si disponible; autenticación/permisos/maker vs admin, canal/publicación con control (práctica DISEÑO/TEST sin exigir publicar); analytics/transcripts/actualización/rollback/consumo cuando habilitado. Mostrar acceso personal vs TI por práctica. No prometer production con simulación.
m7 excel "Excel y Analyst: construir y comprobar análisis" — `excel.{structure,edit,analyse}`. Consolidación archivos, edición formulas dependencias, escenarios/reconciliación. No curso de crédito ni Excel básico. Analyst sin Python local, extracción ≠ libro recalculado.
m8 investigación "Researcher, Pages y Notebooks" — `research.{scope,evidence,workspace}`. Preguntas comparables, evidencia favorable/contraria, actualización; función de Pages vs corpus Notebooks; fuentes primarias, no investigación genérica internet.
m9 comunicación "Word y PowerPoint: producir y mejorar" — `communication.{document,slides,revise}`. Plantilla educativa profesional genérica, transformar análisis en documento y ppt, trabajar existente, tabla/gráfico, narrativa con evidencia, cambios acotados entre aplicaciones. NO FARE ni comités Riesgos obligatorio.
m10 sistema "Reutilizar y automatizar con criterio" — `system.{handoff,automate,transfer}`. Traspasos manuales vs orchestration, programación/Cowork opcionales, medir neto, proyecto FINAL diseñar agente propio cambiando tarea/dominio, no reiterar operación.

15 de 30 lecciones dedicadas de lleno a construir agentes y Studio (m2-m6), más uso desde m1 y transferencia final. Studio 9 lecciones prácticas, rutas visibles, decisiones y fallos. Primero herramienta y capacidad; ejemplos finanzas que sirven a M&A/estructurada/asset management/FP&A, sin presupuestos de experiencia de una especialidad. Licencias/capacidades/tool exactas desde docs oficiales revisor; no genéricas "si disponible" sin alternativa y pérdida.
